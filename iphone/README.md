# Clean Chess for iPhone

Minimal black-and-white iPhone version of Clean Chess.

## Files

- `CleanChessApp.swift` — app entrypoint
- `ContentView.swift` — UI + chess logic

## Run

1. Open Xcode on macOS
2. Create a new **iOS App** project named `CleanChess` if you need a shell project
3. Replace the generated SwiftUI files with these two files
4. Build and run on an iPhone simulator or device

## Notes

- Minimal monochrome UI
- Two-player local chess
- Castling supported
- Pawn promotion to queen
- Undo supported
